# MCP Slim

A lightweight CLI proxy for AI agents that reduces token usage when interacting with MCP (Model Context Protocol) servers.

## Overview

MCP Slim provides a compact, token-efficient interface to MCP servers, making it ideal for AI agents that need to discover and call tools without consuming excessive tokens on verbose JSON schemas.

### Key Features

- 🎯 **Compact tool listings** - View available tools in a concise table format
- 📉 **Reduced token usage** - Up to 70% fewer tokens vs. full MCP JSON schemas
- 🔌 **Native MCP support** - Works with any MCP server via stdio transport
- ⚙️ **Claude Desktop integration** - Reads existing Claude Desktop configurations
- 🚀 **Simple CLI** - Easy-to-use commands for listing and calling tools
